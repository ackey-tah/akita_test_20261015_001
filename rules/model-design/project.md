# モデル設計ルール（プロジェクト）

> 読み込み規約: 同じフォルダの `standard.md` v0.1 を継承する。先に `standard.md` を読み、続けてこのファイルを読む。合成は連結のみ。

## 追記

- **列挙型**（取りうる値の区分だけを表し、振る舞いを持たない型。例: 手の種類 `HandKind`）は、詳細図にステレオタイプ `<<列挙型>>` で描き、値を `物理名（論理名）` の行で並べる。配色は `fill:#B2EBF2,stroke:#006064`（シアン）。理由: 型だけのファイルも domain 層の 1 概念として図に載せる（`npm run check:model-trace` が図に無いファイルを止める）が、標準の配色には該当する種類が無く、Value Object の緑で塗ると振る舞いを持つ値と見分けられないため
