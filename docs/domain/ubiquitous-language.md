# ユビキタス言語

ドメイン用語の定義をここに集約します。境界ごとのモデル図のファイルには重複させません。

| 用語 | 識別子 | 定義 |
| --- | --- | --- |
| プレイヤー | — | ブラウザでじゃんけん画面を開いて遊ぶ 1 人の人。勝敗はプレイヤーから見て判定する |
| 手 | `Hand` | じゃんけんで出すもの。グー・チョキ・パーの 3 種類 |
| グー | `Hand.rock` | チョキに勝ち、パーに負ける手 |
| チョキ | `Hand.scissors` | パーに勝ち、グーに負ける手 |
| パー | `Hand.paper` | グーに勝ち、チョキに負ける手 |
| 手の種類 | `HandKind` | 手がグー・チョキ・パーのどれかを表す区分 |
| 相手 | — | プレイヤーと対戦するコンピュータ。手をグー・チョキ・パーから等しい確率でランダムに選ぶ |
| 勝敗 | `Outcome` | 1 回の勝負をプレイヤーから見た結果。勝ち・負け・あいこの 3 種類 |
| 勝敗の種類 | `OutcomeKind` | 勝敗が勝ち・負け・あいこのどれかを表す区分 |
| 勝ち / 負け | `Outcome.win` / `Outcome.lose` | プレイヤーの手が相手の手に勝った / 負けた勝敗。勝ちと負けを合わせて「勝敗が決まった」と言う |
| あいこ | `Outcome.draw` | 両者が同じ手を出した勝敗。勝敗は決まっておらず、その場で次の手を選ぶ（「あいこでしょ」） |
| 勝負 | `Round` | プレイヤーが手を 1 回選んでから勝敗が判定されるまでの 1 回分。あいこも 1 回の勝負として数える |
| もう一度勝負する | `GameSession.rematch` | 勝敗が決まったあと、結果の表示を消して手の選択に戻る操作 |
| 戦績 | `BattleRecord` | ページを開いてからの勝ち・負け・あいこの回数と、それぞれの割合。ページを再読み込みすると 0 回に戻る |
| 割合 | `Percentage` | 勝ち・負け・あいこの回数の合計に対する、それぞれの回数のパーセンテージ。小数第 1 位を四捨五入した整数。合計が 0 のときは計算できない |
| 対戦の進行 | `GameSession` | 戦績と直前の勝負から、いま手を選べるか・もう一度勝負できるかを決める、ページを開いている間の対戦の状態 |
