# プロダクト

## 目的

ブラウザだけで手軽に遊べる、コンピュータ相手のじゃんけんゲームです。インストールやログインなしで、ページを開けばすぐに遊べ、勝敗と戦績を見ながら何度でも続けられることを目的にします。

## 原則

- **ブラウザだけで完結する。** サーバ処理を持たず、静的ファイルを開くだけで動く。プレイ中に外部へ通信しない
- **相手は公平に手を選ぶ。** 相手（コンピュータ）はプレイヤーの手を見ずに、グー・チョキ・パーを等しい確率で選ぶ
- **戦績は信用できる値にする。** 押した回数と戦績の回数を常に一致させ、計算できない割合は計算できないと表示する
